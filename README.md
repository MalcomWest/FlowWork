# FlowWork 📋

**A simple, interactive Kanban board to organize tasks and manage your workflow.**

FlowWork is a browser-based task management app built using vanilla HTML, CSS, and JavaScript. It lets you organize your work into customizable columns, create task cards, and move tasks between columns using drag and drop.

## ✨ Features

- **Create Columns** — Organize your workflow with custom columns.
- **Add Task Cards** — Create cards with titles, descriptions, due dates, and colors.
- **Delete Tasks** — Remove cards whenever they're no longer needed.
- **Delete Columns** — Remove entire columns from your board.
- **Drag & Drop** — Move task cards between different columns.
- **Persistent Storage** — Your board data is saved using the browser's Local Storage, so it remains available after refreshing the page.
- **Color Customization** — Assign colors to task cards to make them easier to distinguish.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## 💾 Data Storage

FlowWork uses the browser's Local Storage to save board data.

- Data is stored locally in your browser.
- Refreshing the page won't erase your saved tasks.
- Data is not automatically synchronized between different browsers or devices.
